# UI 描述术语表

和 AI 或同事描述界面时用这些词，比"加个动画""做个弹窗"准确得多。术语名称来自 Gabriel 的演示（每组附原帖），中文解释和使用场景为整理。

## 浮层（[原帖](https://x.com/gabriell_lab/status/2115450393744298402)）

| 术语 | 含义 | 什么时候用 |
| --- | --- | --- |
| Modal | 居中对话框，背景变暗，处理后才能回到页面 | 确认、删除、需要用户做决定 |
| Popover | 锚定在触发按钮旁的浮层面板 | 就地选择、筛选、小表单 |
| Tooltip | 悬停出现的小标签，只放一句说明 | 图标按钮名称、快捷键提示 |
| Toast | 角落弹出的短通知，自动消失 | 已保存、已复制、后台完成 |
| Sheet | 从侧边滑入的面板 | 详情、设置、编辑一条记录 |
| Drawer | 从底部滑出的面板 | 移动端操作菜单、补充信息 |

## 滚动（[原帖](https://x.com/gabriell_lab/status/2107443057805476100)）

| 术语 | 含义 | 什么时候用 |
| --- | --- | --- |
| Scroll-triggered | 元素进入视口时触发一次入场动画 | 落地页区块、卡片网格 |
| Scroll-linked | 动画进度与滚动位置绑定 | 阅读进度条、随滚动变化的指标 |
| Parallax | 前后图层速度不同，产生纵深 | 营销页 Hero，产品界面慎用 |
| Sticky | 滚动到顶部时吸附固定 | 分组标题、表头、工具栏 |
| Scroll Snap | 滚动停止时吸附到整页或整卡片 | 分页卡片、引导页、图集 |
| Horizontal Scroll | 内容横向排列、横向滚动 | 卡片轮播、时间线 |

## 加载（[原帖](https://x.com/gabriell_lab/status/2110711852787539974)）

| 术语 | 含义 | 什么时候用 |
| --- | --- | --- |
| Spinner | 转圈，只表示"在等" | 极短、无法估计进度的等待 |
| Progress Bar | 显示确定进度，完成后变对勾 | 上传、导出 |
| Skeleton | 灰色占位块先画出内容骨架 | 列表、信息流、卡片首屏 |
| Optimistic UI | 先显示成功结果，后台再确认 | 发消息、点赞、勾选 |
| Blur-up | 先显示模糊低清图，再过渡到原图 | 大图、相册、封面 |
| Stateful Button | 按钮自身变成加载中 / 已完成 | 保存、提交 |

## 转场（[原帖](https://x.com/gabriell_lab/status/2058217175047901310)，[Shared axis](https://x.com/gabriell_lab/status/2076686595294363837)）

| 术语 | 含义 | 什么时候用 |
| --- | --- | --- |
| Context transition | 同一位置切换模式，内容就地变换 | 工具栏、Tab 切换 |
| Drill transition | 从列表推入下一层详情 | 列表到详情、设置子页 |
| Continuity transition | 被点的元素本身展开成下一个界面 | 卡片到全屏、缩略图到大图 |
| Shared axis | 前后步骤沿同一轴向进出 | 多步表单、引导流程 |

## 悬停（[原帖](https://x.com/gabriell_lab/status/2082799779524833717)）

| 术语 | 含义 | 什么时候用 |
| --- | --- | --- |
| Lift | 轻微上浮，阴影加深 | 可点击卡片、主按钮 |
| Magnetic | 元素被光标轻微吸引 | 少量重点按钮，营销页 |
| Spotlight | 光标位置局部高亮 | 卡片网格，营销页 |
| Tilt | 按光标位置轻微 3D 倾斜 | 展示型卡片 |
| Parallax hover | 内部内容与外框位移不同步 | 图标按钮、插画卡片 |
| Morph | 按钮形状变形延展 | 强调型 CTA，慎用 |
| Proximity（[原帖](https://x.com/gabriell_lab/status/2060336070059864461)） | 光标靠近时周边元素按距离放大 | Dock、工具栏 |
| Direction-aware（[原帖](https://x.com/gabriell_lab/status/2085730524736143521)） | 按光标进入方向决定内容移动方向 | 图片卡片、作品集 |

## 图标动效（[原帖](https://x.com/gabriell_lab/status/2069392205052076091)）

| 术语 | 含义 | 什么时候用 |
| --- | --- | --- |
| Bounce | 弹跳一下 | 新消息、添加成功 |
| Scale | 放大再回弹 | 点击反馈、选中 |
| Rotate | 旋转 | 刷新、同步、展开箭头 |
| Draw | 沿路径画出线条 | 完成对勾、首次出现 |
| Wiggle | 左右小幅晃动 | 提醒注意、不可用 |
| Breathe / Pulse | 缓慢放大缩小 | 录音中、实时状态 |
