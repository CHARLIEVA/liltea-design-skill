# liltea-design

一个面向数字界面的设计技能：重视清晰的信息层级、直觉式交互、视觉对齐和克制的视觉表达，并提供间距、动效数值和 UI 描述术语，方便把需求准确交给 AI。

## 结构

- `SKILL.md`：设计原则、视觉对齐、术语速查和工作方式。
- `references/motion.md`：动效与微交互的具体数值。
- `references/engineering.md`：布局稳定、弹窗、滚动等实现细节清单。
- `references/terms.md`：浮层、滚动、加载、转场、悬停、图标动效术语表。

## 使用

将本仓库内容（`SKILL.md` 和 `references/`）放入 Codex 技能目录 `~/.codex/skills/liltea-design/`，然后在界面设计或视觉审查任务中使用 `$liltea-design`。整体重做会先提供修改清单供确认；明确的小调整可以直接执行。

技能只调整授权范围内的样式、文案与动效，不更改功能、数据或业务逻辑。
